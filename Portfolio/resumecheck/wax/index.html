      Discogs required for prices

      Discogs gives out a free personal token in about a minute: discogs.com/settings/developers → Generate token. Paste it below. It is stored only on this phone and goes nowhere except Discogs.

      Your cut

      The slice you take off the Discogs value to cover fees, shipping, and the fact that the median never quite lands. 30% is a sane default.

      Photo reading optional

      Shooting a label or checking condition sends that one photo to Anthropic's API with your own key. Get a key at console.anthropic.com. Stored on this phone only. Leave it blank and everything else still works — barcode scanning and search need no key.

      A label photo runs a fraction of a cent on Haiku and a few cents on Opus. Rotate the key from the console if you ever lose the phone.

      Install it

      iPhone: Share → Add to Home Screen. Android: the menu → Install app. It then opens full screen with no address bar, and the shell works offline — prices still need signal.
